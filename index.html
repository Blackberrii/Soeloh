The project

Blackthorn

A self-hosted LLM gateway — one shared model budget behind a proxy that hands out individually-limited keys.

Instead of handing my one API key straight to friends, this runs a proxy in front of it that issues each person their own rate-limited, budgeted, revocable key — with a full chat UI, a lineup of purpose-built models, a real tool ecosystem, and private web search on top. Everyone gets a plain read on how much of their own limit is left, plus a real per-message cost estimate — so nobody's guessing what a conversation actually costs.

access invite-only hosting self-hosted router nightshade tools live 42

Not a from-scratch project, and I won't pretend otherwise — it's a few excellent open-source pieces wired together and pointed at each other until they behaved: LiteLLM fronting the models, Open WebUI for the actual chat, SearXNG for search, Postgres keeping score, and a Cloudflare Tunnel so nothing has to touch an open port. My contribution was mostly config files, custom tools, and stubbornness.

Why bother self-hosting

Privacy

Nothing Sold, Nothing Hidden

The proxy, the keys, and anything routed to a local model run on my own hardware and never leave it. Prompts that get bumped to a hosted tier (DeepSeek, for now) go to that provider same as any other API call — but the routing and the spend on every key are mine to see, cap, and revoke, not hidden behind someone else's dashboard.

Cost

One Budget, Split Fairly

A single shared model budget behind the proxy, sliced into individually-limited keys per person — nobody's usage silently eats someone else's headroom.

Control

Revocable, Auditable, Mine

Every key can be capped, rotated, or pulled instantly. No vendor lock-in, no surprise pricing change — the whole stack is config files, and I understand maybe half of them on a good day.

One gateway, a couple of models

Default

Nightshade

The default, invisible router. It reads every prompt and escalates through fast/medium/heavy tiers automatically — a one-liner gets the cheap fast model, "verify this" or "write me a function" gets bumped up to a tier that'll actually check or reason instead of guessing.

Vision

Belladonna

Image-capable tier for anything with a picture attached — reads screenshots, photos, and documents instead of politely refusing. Swapped to a stronger model after the previous one confidently made up details on a real test photo.

Talk to it, get more than text back

Voice

Talk To It, Hear It Back

Push-to-talk in, spoken replies out — free local speech-to-text on the way in, a real streamed voice on the way out. No third-party voice API sitting in the loop either direction.

Images

Local Image Generation

Runs on the same hardware as everything else — a real checkpoint on a local GPU, not a hosted API call. Generate an image straight from a reply, no separate app or account needed.

A real tool ecosystem

Search

Private Web Search

Backed by a self-hosted search engine, not a third-party API — no per-query cost, no external search provider in the loop.

Code

Real Code Execution

Not just Python — code gets actually run and checked against test cases in over a dozen languages before an answer comes back, instead of eyeballing whether it looks right.

Reasoning

Proactive Tool Use

Models are nudged to reach for a tool on their own when it'd beat a guess — and to prefer the purpose-built tool (calculator, converter) over a generic web search when one exists.

Usage

Budget You Can Actually Read

A percentage-left readout on every reply, plus a real per-message dollar estimate before you send — actual costs, not some made-up internal currency you have to convert in your head.
