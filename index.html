The project

BlackberryAI

A self-hosted LLM gateway — one shared model budget behind a proxy that hands out individually-limited keys.

Instead of handing my one API key straight to friends, this runs a proxy in front of it that issues each person their own rate-limited, budgeted, revocable key — with a full chat UI, web search, and voice transcription on top. No dollar figures shown to anyone, just a plain read on how much of their own limit is left.

access invite-only hosting self-hosted router nightshade
Access

Per-Friend Keys

Every friend gets their own virtual key with its own budget and rate limit, so one person's usage can never starve or bankrupt everyone else's — and any key can be revoked on its own.

Routing

Nightshade Auto-Router

Friends see one model. It reads each prompt and automatically routes to a fast tier for simple stuff and a smarter tier for harder questions — nothing to pick.

Search

Private Web Search

Backed by a self-hosted search engine, not a third-party API — no per-query cost, no external search provider in the loop.

Voice

Local Transcription

A GPU-backed transcription service running locally — friends can transcribe audio/video without it costing anyone tokens or touching a paid API.

Usage

Plain-Language Budget

A small line under every reply — "you have roughly X% of your usage left" — no made-up currency, no dollar figures, just an honest read on your real limit.

Invite-only — this runs for friends and family, not the general public. Message me on Discord if you want in.
